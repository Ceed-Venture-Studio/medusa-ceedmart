# Nigerian Laptop Catalogue: Specification and Dropdown Options

For a Nigerian laptop catalogue, prioritise **HP, Dell, Lenovo and Apple**, with **Core i5/Core i7, 8GB/16GB RAM, and 256GB/512GB SSD** configurations prominently displayed.

These are **market-informed dropdown suggestions, not verified national usage rankings**. Nigerian marketplace listings show particularly strong representation of HP and Dell, while local retailers also carry Lenovo, ASUS and Apple. Listings measure availability rather than actual ownership, and seller specifications can be inaccurate.

Sources: [Jiji Nigeria](https://jiji.ng/computers-and-laptops), [SLOT Nigeria](https://slot.ng/), [Jumia business laptops](https://www.jumia.com.ng/mlp-business-laptop/).

The original form mixes laptop selection with desktop assembly. For laptops, the model determines the motherboard, chassis, cooling and usually CPU/GPU. These should not be independently selectable.

**Platform key:** W = Windows laptops; M = Mac; Both = either platform where compatible.

There are 10–20 options where useful. Fields with fewer sensible choices should stay shorter. Broader options provide catalogue coverage; they are not all equally popular in Nigeria.

## Recommended additional fields and customer flow

Add **Model / series** immediately after Brand, then filter specifications against the actual machine.

Also add **Condition**:

- New
- Foreign-used
- Locally-used
- Refurbished

Recommended flow:

**Windows or Mac → Brand → Model → Available memory/storage configuration → Accessories → Setup services**

This provides a useful Nigerian-market catalogue while preventing customers from selecting laptop combinations the manufacturer never made.
